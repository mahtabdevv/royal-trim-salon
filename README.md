# The Royal Trim · Salon for Men

One-page website for The Royal Trim, a men's salon on Abdara Road, Peshawar.

- Full service menu with prices (hair, colour, keratin and treatments, facials, face treatments, waxing)
- Add services and send a pre-filled booking message on WhatsApp (+92 320 5733063)
- Open/closed status on Peshawar time, map and directions, FAQ

Plain static HTML, CSS and JavaScript with no build step. Open `index.html` or host the folder on any static host (GitHub Pages, Netlify, Vercel).

## Files
- `index.html` the whole site
- `img/` service photos, cropped from the salon's printed menu
- `assets/` original menu flyers and logo
